You are a strict evaluator analyzing a language model's chain-of-thought reasoning that ended in abstention (the model chose not to answer).

You will receive:
1. The problem statement and correct answer
2. The model's reasoning as numbered lines

You must answer the following questions:

## 1. Abstention reason

Classify why the model abstained into exactly one category:
- "reached_answer_rejected": The model arrived at a specific answer during reasoning, then expressed doubt or uncertainty and chose to abstain. Look for patterns like computing an answer, then saying "I'm not sure", "this doesn't seem right", "let me reconsider", etc.
- "explored_and_gave_up": The model tried multiple approaches or strategies but could not find a satisfactory answer. Look for repeated attempts with different methods, expressions of being "stuck", etc.
- "early_abstain": The model abstained relatively quickly without extensive exploration. Few attempts were made before giving up.

## 2. Reached answer

If the model arrived at a specific answer at any point (even if it later rejected it), report that answer as a string. If no concrete answer was reached, report null. Only count COMPLETE answers — not intermediate computations or partial results.

## 3. Reached answer correct

If you reported a reached answer above, determine whether it matches the ground truth. true if correct, false if incorrect, null if no answer was reached.

## 4. Verification indices

List the line numbers where the model is VERIFYING or double-checking a result it has ALREADY computed. Verification means revisiting prior work to confirm it is correct.

Do NOT include lines where the model is trying a NEW computation to see if it leads somewhere — that is exploration, not verification. For example, "What if I try 611 / 52 = 11.65. Not helpful." is exploration followed by backtracking, NOT verification.

## 5. Backtrack indices

List the line numbers where the model EXPLICITLY REJECTS a previous approach or result and abandons a line of reasoning to try something different.

## 6. Number of attempts

Count the number of DISTINCT solution strategies or approaches the model tried. A new attempt starts when the model tries a fundamentally different approach, not just a minor variation. Sequential arithmetic tries with different numbers within the same strategy count as ONE attempt.

Return your answer as valid JSON with this exact schema:
{"abstention_reason": "reached_answer_rejected" | "explored_and_gave_up" | "early_abstain", "reached_answer": "<string or null>", "reached_answer_correct": true | false | null, "verification_indices": [<integers>], "backtrack_indices": [<integers>], "num_attempts": <integer>}

Only output valid JSON. Do not include any extra text.
