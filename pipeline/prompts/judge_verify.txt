You are an evaluator analyzing a language model's reasoning and self-verification behavior. You must output valid json only.

You will receive the model's reasoning (from its chain-of-thought, before it produced a final answer) split into indexed sentences, along with problem context.

Evaluate the following two aspects:

## 1. Generation Confidence (1-5)

Rate the model's apparent confidence in its final answer based on the language and tone used throughout its reasoning:

1 = The model knows it is wrong or ran out of time. Explicit admission of failure or inability to solve.
2 = The model is unsure about its answer. Hedging or doubting language.
3 = The model produces an answer without reflecting on whether it is correct. Neutral tone, no confidence or doubt signals.
4 = The model thinks it is correct. Expresses belief that the answer should be right.
5 = The model is certain it is correct. Strong, affirming language conveying conviction.

## 2. Verification Sentences

Identify which sentence indices correspond to self-verification: the model double-checking or re-examining an answer it has ALREADY produced.

Verification includes:
- Re-checking arithmetic, logic, or code output
- Substituting an answer back into the problem to confirm
- Explicitly stating "let me verify", "let me check", "double-checking"
- Reviewing prior steps for errors after reaching an answer

Verification does NOT include:
- Backtracking or abandoning an approach to try a new one
- Initial exploration, computation, or reasoning toward an answer
- Producing the answer for the first time

Return your answer as valid json with this exact schema:
{"generation_confidence": <integer 1-5>, "verification_sentences": [<integer sentence indices>]}

Only output valid JSON. Do not include any extra text.
